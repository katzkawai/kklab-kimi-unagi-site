# 浜名湖うなぎ物語

浜名湖の名産、うなぎの魅力を紹介する静的ウェブサイトです。

## 概要

静岡県浜松市・湖西市にまたがる浜名湖は、日本有数のうなぎの名産地として知られています。このサイトでは、浜名湖の自然と歴史、うなぎの特徴や調理法、おすすめの名店、アクセス情報を余すところなくご紹介しています。

## サイト構成

| ページ | ファイル | 内容 |
|--------|----------|------|
| トップ | `index.html` | ヒーローイメージ、サイト概要、各セクションへの導線 |
| 浜名湖の魅力 | `about-lake.html` | 湖の歴史、四季の風景、おすすめ観光スポット |
| うなぎの世界 | `about-unagi.html` | 400年の歴史、浜名湖うなぎの特徴、蒲焼き・白焼き・肝吸いなどの調理法 |
| 名店紹介 | `shops.html` | 浜名湖周辺の厳選うなぎ料理店6店舗 |
| アクセス | `access.html` | Google Maps、東京・名古屋・大阪からの交通手段、周辺観光スポット |

## 技術スタック

- **HTML5** — セマンティックマークアップ
- **CSS3** — Flexbox/Grid、CSS Variables、メディアクエリによるレスポンシブ対応
- **Vanilla JavaScript** — 軽量なインタラクション（モバイルメニュー、スクロールアニメーション）
- **Google Fonts** — Noto Serif JP / Noto Sans JP

外部フレームワークやビルドツールに依存せず、軽量で高速に動作する設計としています。

## デザイン方針

- **テーマカラー**: うなぎの蒲焼きをイメージした濃い茶色（`#5D4037`）と金色（`#C9A227`）をアクセントに、和紙のようなオフホワイト（`#F5F0E8`）を背景に使用
- **和風モダン**: 伝統的な美意識と現代的な読みやすさを両立
- **モバイルファースト**: スマートフォンからデスクトップまで、あらゆる画面サイズで最適な表示

## 使い方

1. リポジトリをクローンまたはダウンロード
2. `index.html` をブラウザで開く
3. ローカルサーバーで確認する場合:
   ```bash
   # Pythonの場合
   python3 -m http.server 8000

   # Node.jsの場合
   npx serve .
   ```
